## 1. Ordre du jour

Voici les points principaux à l'ordre du jour pour cette séance:

  - Présenter les recherches depuis la dernière séance.
  - Définir la répartition des tâches prioritaires.
  - Choisir les dates des prochaines séances.
  - Effectuer régulièrement un tour de table afin que chacun puisse s'exprimer. Ce point a été intégré à chaque étape de la séance.

## 2. Discussion autour des recherches effectuées

Nous avons effectué un tour de table afin que chacun puisse expliquer et présenter les recherches réalisées depuis la dernière séance.

La plupart de ces recherches ayant déjà été partagées sur le serveur Discord, les membres de l’équipe avaient pu en prendre connaissance au préalable. Cela a permis de consacrer cette partie de la séance principalement aux échanges, aux questions et aux discussions autour des différentes propositions.

## 3. Répartition des tâches prioritaires et prise de décision

  - **Cynthia : Docker**
  Comme décidé lors de la dernière séance, **Docker** sera utilisé pour ce projet. Cynthia prend en charge cette partie et poursuit ses recherches afin de pouvoir présenter une proposition concrète adaptée au projet.
  
  - **Mélody : Frontend**
  Le framework retenu pour le frontend du projet est **Next.js**. Mélody poursuit les recherches déjà commencées depuis la dernière séance afin d’approfondir la stratégie à adopter pour cette partie
  
  - **Marjorie : Base de données**
  Le choix définitif de **PostgreSQL** comme système de gestion de base de données pour le projet a été validé. Cette partie sera traitée en priorité, la base de données constituant l’une des fondations du projet et permettant de relier différents éléments de l’application.
  Pour la prochaine séance, une proposition concernant la stratégie de mise en place de la base de données sera présentée à l’équipe, accompagnée de schémas afin de faciliter sa compréhension.
  
  - **Mathieu : Backend**
  Le framework retenu pour le backend du projet est **NestJS**. Mathieu poursuit les recherches déjà commencées depuis la dernière séance afin d’approfondir la stratégie à adopter pour cette partie.
  
  - **Lisa : se renseigner sur les API**
  Lisa poursuit ses recherches concernant les API afin de pouvoir présenter différentes possibilités et proposer une solution adaptée aux besoins du projet.
 
## 4. Point sur les PV

Les PV continueront d’être envoyés sur le serveur Discord afin d’être relus et validés par l’ensemble du groupe.
Une fois leur version définitive validée, ils seront enregistrés au format `.md` dans un dossier dédié directement sur le dépôt Git du projet.

## 5. Prochaines séances

La prochaine séance se tiendra le **vendredi 25 septembre 2026** — l’heure sera définie à l’aide d’un sondage sur Discord.
La date proposée et prévalidée par l'équipe pour la séance d'après est le **mercredi 30 septembre 2026**.

  - **NestJS** est validé comme framework backend.
