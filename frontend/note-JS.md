Next Js projet  
Commande : npx create-next-app@latest  
( npx outil fournis avec node.js , permet d'executer package sans installer globalement)  
( avec le tag de la derniere version )  

Cette commande va :  
- creer le dossier de projet
- installer next.js, React, node.js
- va faire toute la structure prete a coder
- configure typescript ESLint, etc 

## Getting Started

First, run the development server:
( attention on doit la lancer depuis le dossier front !)

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
